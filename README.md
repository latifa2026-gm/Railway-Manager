# Railway Manager



Application console en JavaScript avec Node.js pour gérer les trajets et les tickets d'un train.



\## Fonctionnalités



\- Afficher les trajets

\- Acheter un ticket

\- Afficher les tickets

\- Annuler un ticket

\- Rechercher un ticket

\- Filtrer les trajets

\- Trier les trajets

\- Afficher des statistiques



\## Technologies



\- JavaScript

\- Node.js

\- Git

\- GitHub
