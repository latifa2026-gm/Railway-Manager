# Railway Manager

Application console en JavaScript avec Node.js permettant de gérer les trajets et les tickets d'un train.

## Description

Railway Manager est une application développée en JavaScript et exécutée avec Node.js.

Elle permet de gérer les trajets d'un train ainsi que les tickets des passagers directement depuis la console.

L'utilisateur peut afficher, rechercher, filtrer et trier les trajets, mais également acheter, afficher, rechercher et annuler des tickets.

## Fonctionnalités

### Gestion des trajets

- Afficher la liste des trajets
- Rechercher un trajet
- Filtrer les trajets
- Trier les trajets
- Afficher les informations d'un trajet
- Afficher les places disponibles

### Gestion des tickets

- Acheter un ticket
- Afficher la liste des tickets
- Rechercher un ticket
- Annuler un ticket
- Mettre à jour le nombre de places disponibles après un achat
- Libérer une place après l'annulation d'un ticket
